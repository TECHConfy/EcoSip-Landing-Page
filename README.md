
# 🌿 EcoSip — Responsive Product Landing Page

A fully responsive and interactive landing page for **EcoSip**, a fictional eco-friendly brand built using **HTML**, **CSS**, and **JavaScript**.  
This project demonstrates modern front-end concepts such as responsive layouts, smooth animations, theme toggling, and interactive features that enhance user experience.

---

## 🚀 Features

- 🧭 **Header + Navigation** — Includes the EcoSip logo and smooth-scrolling navigation links.  
- 🎯 **Hero Section** — Eye-catching banner highlighting the EcoSip product with a strong call-to-action button.  
- 💡 **Features Section** — Displays 5 unique product highlights in well-designed feature cards.  
- 🛒 **Cart System** — Simulate adding, editing, and removing items, with a mock checkout confirmation modal.  
- 📬 **Contact Form** — Includes name, email, and message fields with real-time validation and success messages.  
- 🌗 **Dark/Light Mode** — Toggle between light and dark themes using CSS variables, stored with localStorage.  
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile devices using Flexbox and CSS Grid.

---

## 🧰 Tech Stack

- **HTML5** – Page structure and semantics  
- **CSS3 (Flexbox & Grid)** – Layout, responsiveness, and styling  
- **JavaScript (ES6)** – Interactivity, DOM manipulation, and form validation  

---

## ⚙️ Installation & Setup

1. Clone this repository:
   ```bash
   git clone https://github.com/TECHConfy/EcoSip.git
````

2. Navigate into the project directory:

   ```bash
   cd EcoSip
   ```

3. Open the project:

   * Simply open the `index.html` file in your browser, or
   * Use a local server (like VS Code **Live Server** extension) for best experience.

---

## 🎮 Usage

* Click **Add to Cart** to simulate adding items to your cart.
* Use **Edit** or **Remove** to manage items inside the cart modal.
* Click **Checkout** to view a fictional confirmation message.
* Fill out the **Contact Form** — input validation ensures proper email and non-empty fields.
* Toggle **Dark/Light Mode** — your choice is automatically saved via localStorage.
* Smoothly navigate between sections using the sticky header links.
